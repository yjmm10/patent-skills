# 论文写作终极检查清单

用于 **diagnose** 与 **self_check** 阶段。每项标记 ✅ / ⚠️ / ❌。

---

## 结构与篇幅

- [ ] 标题含：方法 + 场景 + 核心技术
- [ ] 摘要 5 句：背景→问题→方法→创新→效果
- [ ] 引言倒金字塔：时代→场景→挑战→方案→贡献→结构
- [ ] 相关工作三步：分类→对比→定位
- [ ] 系统模型四层：场景→信道→行为→问题
- [ ] 方法链：转化→架构→模块→复杂度
- [ ] **实验章 3–5 小节**：Setup 在前；4 节版含独立 Convergence + Ablation
- [ ] 实验内容六维覆盖：收敛→对比→（规模/敏感）→消融→（场景）
- [ ] 结论三段：总结→局限→未来

---

## 表达与逻辑

- [ ] 段首承接、段末引出；**章际**有过渡句（writing-principles）
- [ ] **子节过渡三级**：战略（§→§-A）/ 战术（§-A→§-B）/ 操作（§-A→§-A1）无断崖
- [ ] 战术级含 However/Therefore/Consequently；操作级主动语态
- [ ] 每 100 词约 2–3 个逻辑连接词（非机械堆砌）
- [ ] 术语与缩写全文一致
- [ ] 无空洞形容词堆砌（novel/innovative 无机制支撑）

---

## 公式与算法

- [ ] 每个符号首次出现有定义
- [ ] 优化问题标注复杂度（NP-hard / non-convex 等）
- [ ] 伪代码含 Input/Output/关键步骤（**无** Python 语法）
- [ ] Reward/目标函数有物理意义解释
- [ ] **无**正文函数名/类名/文件路径（见 code-abstraction）

---

## 代码与实现抽象化

- [ ] 正文无 `.py` / `.yaml` 路径、`configs/`、`./results/`
- [ ] 无库版本号（torch==x.x）；技术栈用方法论表述
- [ ] 无 `def`/`class`/行号引用；训练流程用 Algorithm 1 或数学期望
- [ ] 超参数**数值**可留正文；**代码位置**不可留
- [ ] 实现细节建议 Appendix；代码链在脚注/致谢
- [ ] 实验指标用数学定义 + 统计方法（非 `results['key']`）

---

## 图表

- [ ] Fig.1 系统场景；Fig.2 算法架构（职责不混）
- [ ] 图题自解释（含关键结论或参数）
- [ ] 曲线图：本文红色实线 + 置信区间/误差棒
- [ ] 至少 1 个轨迹或深入可视化（若适用）
- [ ] Table I 仿真参数；消融/对比有独立表

---

## 实验章小节结构（Section V）

- [ ] 子节数量 3–5（非 <3 或 >6）
- [ ] 逻辑顺序：设置 → 训练/收敛 → 性能对比 → 消融/深入分析
- [ ] V-A：Table I + 3–5 baselines + 4–6 指标（三类）
- [ ] 收敛性：独立小节或 3 节版 B 首段 + 独立 Fig.4
- [ ] V-C（或等价节）：主结果 + 多场景 + 统计显著性
- [ ] 消融：独立小节（4/5 节版）；单组件移除 + 量化 %
- [ ] 每小节 300–400 词；每节 ≥1 核心图/表；小节末有过渡句
- [ ] 全章实验图 5–8 个

---

## 实验说服力（内容）

- [ ] 3–5 个合理 baselines
- [ ] 4+ 评估指标（效能/效率/鲁棒性）
- [ ] 量化对比（非 only "better"）
- [ ] 消融证明各创新点必要性
- [ ] 主张均有 Fig./Table/文献支撑

---

## 摘要与结论数字

- [ ] 摘要含 2–3 个具体数值
- [ ] 结论有技术洞察（非复制粘贴摘要）
- [ ] 四个关键数值在文中前后一致

---

## 格式与合规

- [ ] 无拼写/语法硬伤（润色层可标注待查项）
- [ ] 符合目标期刊参考文献与格式（用户指定）
- [ ] 未捏造数据或引用

---

## 好论文 DNA 快速扫描

| 要素 | 检查 |
|------|------|
| 一个核心贡献 | 全文是否围绕单一主线 |
| 两张核心图 | Fig.1/2 + 关键结果图是否清晰 |
| 三类对比 | 经典 / SOTA / 消融 |
| 四个关键数值 | 摘要+结论是否量化 |
| 五层逻辑 | 段间是否递进 |

---
